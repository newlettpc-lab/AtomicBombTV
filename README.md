# AtomicBombTV
AtomicBombTV es un programa para ver tus canales de TV favoritos a base de servidores extraídos de internet. Dedicado a Españoles y con canales hispanos, AtomicBombTV te ofrece la mejor variedad de canales desde TDT hasta Deportes en directo.
Versión Actual: 1.7 (17 Noviembre 2026)
MODO DE USO
WINDOWS 10/11: 1. Descarga el .zip 
2. Descomprime el .zip
3. Asegúrate no tener VPN's activas
4. Ejecuta AtomicBombTV.bat y sigue las instrucciones.

MacOS: En Desarrollo
